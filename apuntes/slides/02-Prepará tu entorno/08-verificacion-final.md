# Verificación final

Última parada antes de la clase 1. Vamos a confirmar, **uno por uno**, que todo responde — así llegás 100% listo y no perdemos tiempo en setup. Tomate 5 minutos y pasá esta lista. ✅

## 🧪 El checklist (con qué deberías ver)

Corré cada comando en la terminal y fijate la respuesta:

**1. Node** (≥ 22):

```
node --version
```

→ deberías ver algo como `v22.x.x`. ✅

**2. Git:**

```
git --version
```

→ `git version 2.x.x`. ✅

**3. Python** (≥ 3.12):

```
python3 --version
```

→ `Python 3.12.x` o mayor. ✅

**4. Spec Kit (CLI):**

```
specify --version
```

→ un número de versión. ✅

**5. Claude Code:** corré `claude` en una carpeta de prueba y pedile que cree un archivo. ¿Responde y lo crea? ✅

**6. GitHub Copilot:** corré `copilot` en una carpeta de prueba y pedile una tarea simple. ¿La hace? ✅

**7. OpenCode:** corré `opencode` y pedile algo. ¿Responde? ✅

**8. GitHub:** confirmá que estás logueado. Si tenés el CLI de GitHub, `gh auth status`. ✅

Si los ocho dan verde, **estás listo, Builder**. 🎉

## 🧭 Cómo vas a trabajar de acá en adelante

Un recordatorio importante, porque define todo el curso:

- **Acá NO creaste ningún repositorio** — y está bien así.
- En el **Módulo 1** vas a escribir el **PRD** de tu proyecto (el documento que define qué construís).
- A partir del **Módulo 2**, **cada método tiene su propio repo** para construir tu app (vibecoding en M2-M3, después Spec Kit, después tu pipeline…). Lo único que viaja entre todos es el PRD.

Así que no busques «el repo del curso»: **vas a tener varios**, y los vas creando sobre la marcha. 😉

## 🆘 Si algo quedó en rojo

No vengas a la clase 1 con un ítem en rojo (vas a arrancar trabado y te perdés lo bueno). Si algo no dio verde:

1. Volvé a la lección de ese tool y revisá la sección **«Si algo no sale»**.
2. Si sigue, **dejá tu consulta en los comentarios al pie de esta lección** con el **error concreto** (qué comando corriste + el mensaje que te dio) y te ayudamos — ese es justamente el momento de usarlos.

Nos vemos en la clase 1. A construir, Builder. 🚀
